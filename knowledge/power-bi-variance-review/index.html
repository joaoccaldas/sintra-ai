What the numbers support

  • Revenue is EUR 1,350 below the EUR 21,000 budget (-6.43%).
  • Plus contributes −EUR 2,400 and Services −EUR 500; Core contributes +EUR 1,550.
  • New offer has a zero budget and zero actual. Its percentage variance is undefined, not 0%.
  • The arithmetic bridge is not evidence of why demand or pricing changed. Ask the commercial owner before assigning a cause.

Reproduce it in Power BI

  1. Download the CSV. In a new Power BI Desktop file, import it as FinanceVariance. Keep fiscalPeriod as text, and quantity and cents as whole numbers.
  2. Open DAX Query View and paste the query below. It defines temporary query measures and returns product details plus an IsTotal=true row in one result table.
  3. Compare every row and total to this table. For live data, inspect the accessible report through Fabric IQ and reuse its approved measures and exact filters.
Sample data (CSV) ↓DAX query ↓Power Query import ↓Data, results & evidence (JSON) ↓
Inspect the read-only DAX query
DEFINE
  MEASURE FinanceVariance[Demo Actual] = CALCULATE(SUM(FinanceVariance[amountCents]), FinanceVariance[scenario] = "Actual") / 100
  MEASURE FinanceVariance[Demo Budget] = CALCULATE(SUM(FinanceVariance[amountCents]), FinanceVariance[scenario] = "Budget") / 100
  MEASURE FinanceVariance[Demo Variance] = [Demo Actual] - [Demo Budget]
  MEASURE FinanceVariance[Demo Variance Pct] = DIVIDE([Demo Variance], ABS([Demo Budget]))
EVALUATE
  SUMMARIZECOLUMNS(
    ROLLUPADDISSUBTOTAL(FinanceVariance[product], "IsTotal"),
    TREATAS({"Demo Europe"}, FinanceVariance[entity]),
    TREATAS({"2026-09"}, FinanceVariance[fiscalPeriod]),
    TREATAS({"EUR"}, FinanceVariance[currency]),
    "Actual", [Demo Actual], "Budget", [Demo Budget],
    "Variance", [Demo Variance], "VariancePct", [Demo Variance Pct]
  )
ORDER BY [IsTotal], FinanceVariance[product]
What HoldingCo and Finance AI Lab verified

The existing PVM engine returned the same budget, actual and variance. Its price/volume/mix bridge is €150 / -€1,235 / -€265, with a reconciliation delta below one cent. The weighted-average convention allocates arithmetic effects; it does not establish causes.

The result uses Finance AI Lab’s existing contract: dry run, derived from synthetic inputs, locally verified. The receipt pins the dataset and source-code hashes. No model, database or live tenant was called.

What the sources establish

  • Fabric IQ exposes discovery, metadata and DAX execution tools. The calling agent composes the analysis; the server does not supply a natural-language answer itself.[1]
  • DAX DIVIDE returns BLANK for a zero denominator by default. SUMMARIZECOLUMNS groups query results; this example uses query-scoped measures and explicit entity, period and currency filters.[2][3]

Before you start

  • Access to the finance report through Fabric IQ.
  • Actual and budget measures, fiscal period, reporting currency, sign convention and entity scope agreed with the report owner.

A practical starting point

Sintra’s suggested procedure. Validate it in your own environment.

  1. Find the finance report and inspect its filters, schema and measure definitions.
  2. Resolve the exact entity and period values. Reuse the approved measures in a read-only DAX query.
  3. Compare actual and budget at the same grain. Separate absolute variance from percentage variance; flag a zero budget.
  4. Reconcile the total to the report. Attribute drivers only where returned data supports them; list unexplained residuals.

What you should get

Variance table, query and filter receipt, driver commentary, and open questions.

How to check the result

  • The query total matches the report under identical filters.
  • Driver amounts sum to total variance; currency, period and denominator are explicit.
  • Narrative distinguishes observed differences from causal hypotheses.

Try this prompt

Using my accessible finance report, inspect the schema and report filters first. For [entity], [fiscal period] and [currency], compare the approved Actual and Budget measures at the same grain. Show DAX, filters, absolute variance and percentage variance, handling a zero budget explicitly. Reconcile to the report total, then describe supported drivers and unexplained residuals. Do not modify the model or invent figures.

Limits of this brief

  • The public synthetic calculation is tested and cross-checked against HoldingCo. Power BI DAX, Power Query, OAuth, MCP, permissions and live tenant totals have not been exercised.
  • Commentary is authored from deterministic results; no LLM quality benchmark or business impact is claimed.
  • This revenue-only example rejects negative inputs and missing scenario rows. Expense favorability, credits, FX and real fiscal calendars need separate policies.
  • An LLM explanation cannot establish causality from aggregated variance alone.
