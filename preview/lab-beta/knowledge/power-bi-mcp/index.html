Capability guide

Choose the right Power BI MCP server

Query a report, change a semantic model, or support an older client: start with the right connection.

Sources checked 2026-10-18Review due 2026-11-17No Sintra execution test

What the sources establish

  • Microsoft recommends Fabric IQ for consumption. It is generally available and reads reports and semantic models using delegated user access; RLS and OLS apply.[1]
  • Fabric IQ uses Streamable HTTP at https://fabriciq.svc.cloud.microsoft/v1/mcp/fabriciq. Its client discovers tools at runtime; service-principal authentication is unsupported.[1]
  • The earlier Consumption endpoint remains preview at https://api.fabric.microsoft.com/v1/mcp/powerbi. It requires tenant enablement and Build permission. Its Generate Query tool additionally requires Copilot licensing; client-generated DAX is an alternative.[2]
  • Authoring changes semantic models. Hosted is preview at https://api.fabric.microsoft.com/v1/mcp/powerbi/authoring; local is GA and also reaches Desktop, PBIP and TMDL files. This is separate from report-building skills.[3]

Before you start

  • An MCP client supporting the chosen transport and authentication flow.
  • A Microsoft Entra work or school account with access to the target content; check the selected server’s own requirements.

How to choose

Sintra’s suggested procedure. Validate it in your own environment.

  1. For questions about existing reports, start with Fabric IQ and its companion skill.
  2. For measure or model changes, select Authoring; choose local when working with Desktop or files.
  3. Use the older Consumption endpoint only when that is the integration you intend to support.

What you should get

A connection choice with its access requirements and scope recorded.

How to check the result

  • Complete the MCP handshake and inspect tools/list.
  • Read the intended model’s schema and reconcile one known total before broader analysis.

Limits of this brief

  • Sintra documents these servers; it does not connect to your tenant.
  • Tool contracts and availability can change. Follow the linked setup guide for your client.
